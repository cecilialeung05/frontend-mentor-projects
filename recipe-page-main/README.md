## Overview

This is my solution to the **Recipe Page** challenge inspired by Frontend Mentor. The goal of this project was to build a clean, responsive recipe page using semantic HTML and modern CSS.

The page showcases a simple omelette recipe, including preparation time, ingredients, instructions, and nutrition information, styled in a minimal and user-friendly layout.

## My Process

### Built With

- Semantic HTML5
- CSS3 (Flexbox and custom properties)
- Mobile-first responsive layout
- Font: Young Serif, Outfit (via Google Fonts)
- BEM-style CSS class naming
- Accessible color contrast

## What I Learned

- How to structure semantic HTML with clear hierarchy (`<section>`, `<article>`, `<ul>`, `<time>`)
- Using flexbox for vertical layout and spacing
- Creating visually distinct sections (e.g., prep time box, nutrition table)
- Ensuring responsive behavior across different screen sizes
